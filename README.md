# Iran Stock Intelligence

سامانه تحلیل بنیادی بازار سرمایه ایران؛ نسخه آغازین MVP با تمرکز بر نماد **ساروم**.

## قابلیت‌های این اسکلت
- API مبتنی بر FastAPI و PostgreSQL
- مدل اطلاعیه‌های کدال با `tracing_no` یکتا و نگهداری نسخه اسناد
- ثبت قیمت‌های روزانه TSETMC با کلید نماد/تاریخ
- مسیر توسعه برای دریافت اطلاعیه، دانلود فایل خام، استخراج صورت‌های مالی و محاسبه نسبت‌ها
- اجرای محلی با Docker Compose

> وضعیت: اسکلت نرم‌افزاری اولیه است. اتصال زنده به کدال/TSETMC، parser فایل‌های PDF/Excel، زمان‌بندی، فرانت‌اند و تست انتها‌به‌انتها هنوز تکمیل نشده‌اند. داده مالی واقعی در این مخزن seed نشده است.

## اجرا
```bash
cp .env.example .env
docker compose up --build
```
سپس مستندات API در http://localhost:8000/docs در دسترس است.

## ساختار
```
backend/
  app/
    main.py       # FastAPI routes
    config.py     # environment settings
    db.py         # SQLAlchemy session
    models.py     # relational schema
    schemas.py    # API schemas
    services/     # external data adapters
  requirements.txt
  Dockerfile
docker-compose.yml
```

## طراحی داده و اصول
- `codal_announcements.tracing_no` شناسه یکتای اطلاعیه کدال است.
- فایل خام و نسخه‌های اصلاحی باید مستقل از داده استخراج‌شده نگهداری شوند.
- نسخه حسابرسی‌شده و حسابرسی‌نشده رکوردهای مجزا هستند.
- برای جلوگیری از look-ahead، زمان انتشار، دوره مالی، زمان دریافت و زمان ثبت داده جداگانه ذخیره می‌شوند.
- تمام مبالغ باید همراه واحد و ارز ثبت شوند؛ ارقام نمایشی نباید جایگزین مقدار خام شوند.

## توسعه بعدی
1. اعتبارسنجی API جست‌وجوی کدال و پیاده‌سازی pagination/retry
2. دانلود و hash فایل‌های اصلی و تشخیص اصلاحیه‌ها
3. parser فایل‌های Excel/PDF و نگاشت اقلام استاندارد
4. دریافت و ذخیره تاریخچه قیمت/سهام از TSETMC
5. محاسبه نسبت‌های TTM و داشبورد
6. تست‌های یکپارچه و CI

## هشدار
این نرم‌افزار ابزار پژوهش و تحلیل است و توصیه سرمایه‌گذاری یا تضمین صحت داده ارائه نمی‌کند.
