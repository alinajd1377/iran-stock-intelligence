# Iran Stock Intelligence

سامانه تحلیل بنیادی بازار سرمایه ایران؛ نسخه آغازین MVP با تمرکز بر نماد **ساروم**.

## اجرای محلی با Docker

پیش‌نیازها:
- نصب Docker Desktop در Windows/macOS یا Docker Engine و Compose در Linux
- اجرای Docker
- Git برای clone کردن مخزن

دستورها در ترمینال:

```bash
git clone https://github.com/alinajd1377/iran-stock-intelligence.git
cd iran-stock-intelligence
```

در Windows PowerShell:
```powershell
Copy-Item .env.example .env
docker compose up --build
```

در macOS/Linux:
```bash
cp .env.example .env
docker compose up --build
```

بعد از بالا آمدن سرویس‌ها:
- مستندات و تست API: http://localhost:8000/docs
- سلامت API: http://localhost:8000/health
- سلامت دیتابیس: http://localhost:8000/health/db

برای توقف: `Ctrl+C` و سپس `docker compose down`.
برای حذف دیتابیس محلی و تمام داده‌های ذخیره‌شده: `docker compose down -v` (با احتیاط؛ غیرقابل‌بازگشت است).

## APIهای فعلی

- `GET /api/v1/symbols` فهرست نمادهای ثبت‌شده
- `GET /api/v1/announcements?symbol=ساروم` اطلاعیه‌های ذخیره‌شده
- `POST /api/v1/sync/codal/ساروم?pages=1` تلاش برای دریافت و ثبت اطلاعیه‌های کدال

نمونه فراخوانی sync:
```bash
curl -X POST "http://localhost:8000/api/v1/sync/codal/%D8%B3%D8%A7%D8%B1%D9%88%D9%85?pages=1"
```

## آنچه در این نسخه وجود دارد
- FastAPI و PostgreSQL با Docker Compose
- ساخت خودکار جداول دیتابیس در اولین اجرا و ثبت نماد ساروم
- شناسه یکتای اطلاعیه کدال با `tracing_no`
- ذخیره payload خام پاسخ کدال برای lineage و بررسی بعدی
- جدول نسخه فایل‌های خام با hash
- جدول داده‌های مالی استخراج‌شده و قیمت روزانه
- endpoint اولیه همگام‌سازی کدال و فهرست اطلاعیه‌ها

## محدودیت‌های مهم فعلی
این نسخه هنوز محصول کامل یا سیستم داده قابل اتکای سرمایه‌گذاری نیست:
- قرارداد API کدال و ساختار پاسخ آن باید با پاسخ زنده اعتبارسنجی شود؛ endpoint ممکن است تغییر کند.
- دانلود فایل‌های اصلی، parser اکسل/PDF و استخراج خودکار اقلام هنوز کامل نشده‌اند.
- آداپتور TSETMC هنوز به چرخه ذخیره‌سازی قیمت‌ها متصل نشده است.
- نسبت‌های TTM و P/E، P/B، P/S، داشبورد، پیش‌بینی، سبد و اشتراک هنوز پیاده‌سازی نشده‌اند.
- ایجاد جدول با `create_all` فقط برای شروع توسعه محلی است؛ پیش از محیط عملیاتی باید migrationهای Alembic اضافه شوند.
- هنوز اجرای واقعی Docker و تست end-to-end از این محیط انجام نشده است.

## نقشه راه توسعه
1. پایدارسازی اتصال Codal، pagination، retry، checkpoint و ذخیره فایل خام
2. parser فایل‌های Excel/PDF و مدیریت اصلاحیه/حسابرسی
3. دریافت و ذخیره تاریخچه قیمت و اطلاعات سهام از TSETMC
4. مدل استاندارد صورت‌های مالی، داده‌های ماهانه و محاسبه نسبت‌های TTM
5. داشبورد وب و گزارش محصول‌محور/صنعتی
6. پیش‌بینی مالی، موتور پیشنهاد سبد، تحلیل ریسک و اشتراک‌ها
7. migration، تست خودکار، CI و مانیتورینگ

## اصول طراحی داده
- `tracing_no` کلید یکتای اطلاعیه است؛ نماد و دوره مالی به تنهایی یکتا نیستند.
- نسخه‌های فایل و اصلاحیه‌ها باید مستقل نگهداری شوند.
- نسخه حسابرسی‌شده و حسابرسی‌نشده باید قابل تفکیک باشند.
- زمان انتشار، دوره مالی، زمان دریافت و زمان ثبت داده باید جدا باشند تا از look-ahead جلوگیری شود.
- هر مقدار مالی باید همراه واحد، ارز و منبع نگهداری شود.

این نرم‌افزار ابزار پژوهش و تحلیل است و توصیه سرمایه‌گذاری یا تضمین صحت داده ارائه نمی‌کند.
